## 1. Описание модели

Сверточные нейронные сети (CNN) широко применяются в задачах компьютерного зрения, однако их стандартные операции ограничены фиксированной геометрией рецептивных полей. Это приводит к снижению качества при работе с объектами, обладающими сложной формой, масштабными изменениями, поворотами или деформациями.

В работе *Deformable Convolutional Networks* предложены два новых модуля, расширяющих возможности стандартных CNN:

* **деформируемая свёртка (Deformable Convolution)**;
* **деформируемый RoI Pooling (Deformable RoI Pooling)**.

Оба модуля основаны на идее введения **обучаемых смещений** в точки выборки признаков. Смещения обучаются энд-ту-энд из целевой задачи без дополнительного надзора и позволяют сети адаптировать форму рецептивного поля под геометрию объекта.

## 1.1 Проблема стандартных свёрток

Обычные свёртки используют фиксированную регулярную сетку точек для выборки признаков. Формально операция стандартной свёртки задаётся как:

$$
y(p_0) = \sum_{k=1}^{K} w_k \cdot x(p_0 + p_k)
$$

где:

* $y(p_0)$ — значение выходного признака в позиции $p_0$;
* $x(\cdot)$ — входная карта признаков;
* $w_k$ — веса ядра свёртки;
* $p_k$ — фиксированные позиции точек ядра (например, для ядра $3 \times 3$, $K = 9$).

Фиксированность набора $p_k$ ограничивает способность сети адаптироваться к геометрическим искажениям объектов.

![Пример обычной свёртки](img/standard_conv.png)

## 1.2 Деформируемая свёртка (Deformable Convolution)

В деформируемой свёртке к каждой точке выборки добавляется **обучаемое смещение** $\Delta p_k$. Операция принимает вид:

$$
y(p_0) = \sum_{k=1}^{K} w_k \cdot x(p_0 + p_k + \Delta p_k)
$$

где:

* $\Delta p_k$ — обучаемое смещение для $k$-ой точки ядра;
* остальные обозначения совпадают со стандартной свёрткой.

Поскольку обучаемые смещения $Δp$ принимают вещественные значения, точки выборки не совпадают с целочисленными координатами карты признаков. Для получения значений 
$x(⋅)$ в таких дробных координатах используется билинейная интерполяция, представляющая значение признака как взвешенную сумму четырёх ближайших пикселей. Данный метод является дифференцируемым по координатам, что позволяет обучать смещения $Δp$ методом обратного распространения ошибки.

![Схема деформируемой свёртки](img/deformable_conv.png)
## 1.3 Region of Interest (RoI)

**Region of Interest (RoI)** — это прямоугольная область на карте признаков, соответствующая предполагаемому положению объекта на изображении.
RoI обычно формируется на основе:

* региональных предложений (Region Proposal Network, RPN);
* либо выходов детектора в виде ограничивающих прямоугольников (bounding boxes).

Формально RoI задаётся координатами:

$$
\text{RoI} = (x_{\min}, y_{\min}, x_{\max}, y_{\max})
$$

где:
* $(x_{\min}, y_{\min})$ соответствуют координатам верхнего левого угла области
* $(x_{\max}, y_{\max})$ — координатам нижнего правого угла.

Ширина и высота области вычисляются как:
$$
w=x_{\max}−x_{\min}​, h=y_{\max}​−y_{\min}​.
$$
Поскольку размеры RoI могут различаться, операции RoI Pooling и RoI Align приводят признаки из этих областей к фиксированному пространственному разрешению (например, $7 \times 7$), пригодному для последующей обработки.

## 2. Deformable RoI Pooling

В стандартном RoI Pooling точки выборки внутри RoI располагаются по фиксированной сетке, что ограничивает точность выравнивания признаков.
**Deformable RoI Pooling** устраняет это ограничение за счёт введения обучаемых смещений точек выборки внутри каждой области RoI.

Формально значение выходного признака для бина с координатами $(i, j)$ вычисляется как:

$$
y(i,j) = \frac{1}{n} \sum_{k=1}^{n} x(p_{ij,k} + \Delta p_{ij,k})
$$

где:

* $p_{ij,k}$ — фиксированная позиция $k$-ой точки выборки внутри бина $(i,j)$;
* $\Delta p_{ij,k}$ — обучаемое смещение данной точки;
* $n$ — количество точек выборки в бине;
* $x(\cdot)$ — значение карты признаков, получаемое с билинейной интерполяцией.

![Deformable RoI Pooling](img/deformable_roi.png)

### Роль полносвязного слоя (`fc`)

Смещения $\Delta p_{ij,k}$ предсказываются **полносвязным слоем (`fc`)**, который получает агрегированные признаки всей области RoI.
Использование `fc` слоя позволяет учитывать **глобальную форму объекта**, а не только локальный контекст, что особенно важно для корректной геометрической адаптации сетки выборки.

Таким образом, Deformable RoI Pooling позволяет динамически подстраивать расположение точек выборки под форму объекта.

## 3. Эволюция Deformable ConvNets

### 3.1 DCNv1 (2017)

**Основные особенности:**

* введение деформируемой свёртки и деформируемого RoI Pooling;
* предсказание смещений отдельными ветвями сети;
* энд-ту-энд обучение без дополнительной разметки.

**Результаты:**

* +2.6% mAP для R-FCN на COCO;
* +4.9% mIoU для DeepLab на Cityscapes.

**Ограничения:**

* отсутствие контроля вклада отдельных точек;
* проблемы при выходе смещений за границы изображения.


### 3.2 DCNv2 (2019)

В DCNv2 введены **модулирующие маски**, позволяющие регулировать вклад каждой точки выборки:

$$
y(p_0) = \sum_{k=1}^{K} w_k \cdot m_k \cdot x(p_0 + p_k + \Delta p_k)
$$

где $m_k \in [0,1]$ — модулирующий коэффициент.

DCNv2 демонстрирует лучшую стабильность обучения и более высокое качество на задачах детекции и классификации.


### 3.3 DCNv3 (2023+)

DCNv3 ориентирован на современные архитектуры и большие модели:

* улучшенная параметризация смещений;
* оптимизация вычислений;
* интеграция в современные PyTorch-библиотеки;
* применение за пределами классического CV (например, CTR-предсказание).

### 3.4 Сравнение версий

| Характеристика | DCNv1 (2017) | DCNv2 (2019) | DCNv3 (2023+) |
|----------------|--------------|--------------|---------------|
| Смещения | ✓ | ✓ | ✓ (улучшено) |
| Модулирующие маски | ✗ | ✓ | ✓ (улучшено) |
| Обработка границ | Проблемы | Исправлено | Оптимизировано |
| Скорость работы | Базовая | +15-20% к DCNv1 | +5-10% к DCNv2 |
| Интеграция с современными архитектурами | Ограниченная | Хорошая | Отличная |
| Поддержка фреймворков | MXNet (оригинальная) | MXNet, PyTorch | PyTorch, TensorFlow |
| Применение | Детекция, сегментация | Детекция, сегментация, классификация | Мультимодальные задачи, CTR-предсказание |

Сравнительные результаты показывают, что каждая новая версия DCN значительно улучшает качество работы с геометрически сложными объектами, при этом сохраняя вычислительную эффективность и обеспечивая легкую интеграцию в существующие архитектуры нейронных сетей.


## 4. Примеры работы с `torchvision.ops.DeformConv2d`

### 4.1 Минимальный пример

```python
import torch
from torchvision.ops import DeformConv2d
from torchvision import transforms
from PIL import Image
import matplotlib.pyplot as plt
import numpy as np


IMAGE_PATH = "../img/2010_003781.jpg"
OUTPUT_FEATURE = "../img/dcn_output.png"

# --- Загружаем изображение ---
img = Image.open(IMAGE_PATH).convert("RGB")
transform = transforms.Compose([
    transforms.Resize((256, 256)),
    transforms.ToTensor()
])
x = transform(img).unsqueeze(0)  # [1, 3, H, W]

# --- Слой DeformConv2d ---
dcn = DeformConv2d(
    in_channels=3,
    out_channels=16,  # больше каналов для выявления признаков
    kernel_size=3,
    padding=1
)

# --- Генерация случайных offsets ---
offset = torch.randn(1, 2*3*3, x.shape[2], x.shape[3])

# --- Прямой проход ---
y = dcn(x, offset)  # [1, 16, H, W]

# --- Усреднение каналов для наглядного отображения ---
y_mean = y.mean(dim=1, keepdim=True)  # [1, 1, H, W]

# --- Нормализация для визуализации ---
y_vis = y_mean.squeeze().detach().numpy()
y_vis = (y_vis - np.min(y_vis)) / (np.max(y_vis) - np.min(y_vis))

# --- Сохраняем и отображаем результат ---
plt.figure(figsize=(6,6))
plt.imshow(y_vis, cmap='gray')
plt.axis('off')
plt.savefig(OUTPUT_FEATURE, bbox_inches='tight')
plt.show()
````
![Пример детекции объектов с DCN](img/dcn_output.png)

### 4.2 Применение в детекции объектов (MMDetection)

Для практической демонстрации использована реализация DCN в составе Faster R-CNN из библиотеки MMDetection.

```python
import mmcv
    from mmdet.apis import init_detector, inference_detector
    from mmdet.registry import VISUALIZERS
    from mmdet.utils import register_all_modules

    register_all_modules()

    # Конфиг и чекпоинт DCN v1
    config = '../mmdetection/configs/dcn/faster-rcnn_r50-dconv-c3-c5_fpn_1x_coco.py'
    checkpoint = '../mmdetection/checkpoints/faster_rcnn_r50_fpn_dconv_c3-c5_1x_coco_20200130-d68aed1e.pth'

    # Путь к изображению
    img_path = '../img/2010_003781.jpg'

    # Инициализация модели
    model = init_detector(config, checkpoint, device='cpu')

    # Инференс
    result = inference_detector(model, img_path)

    # Визуализация
    visualizer = VISUALIZERS.build(model.cfg.visualizer)
    visualizer.dataset_meta = model.dataset_meta

    img = mmcv.imread(img_path)
    img = mmcv.imconvert(img, 'bgr', 'rgb')

    # Сохраняем результат в ../img/dcn_result.jpg
    visualizer.add_datasample(
        'dcn_result',
        img,
        data_sample=result,
        draw_gt=False,
        show=False,  # не открываем окно
        out_file='../img/dcn_result.jpg'
    )
```

## Заключение

* Deformable ConvNets расширяют возможности CNN при работе с геометрически сложными объектами.
* Обучаемые смещения позволяют адаптировать рецептивные поля под форму объекта.
* Современные реализации (torchvision, MMDetection, DCNv3) обеспечивают практическую применимость подхода.
* Использование Deformable RoI Pooling улучшает качество выравнивания признаков в задачах детекции.
