
# CPMC Proposals Python Implementation

## Описание проекта

Этот проект реализует метод **Constrained Parametric Min-Cuts (CPMC)**, описанный в статье:

> Carreira, J., & Sminchisescu, C. (2010). *Constrained Parametric Min-Cuts for Automatic Object Segmentation*. IEEE TPAMI.

**CPMC** генерирует несколько предложений сегментации объектов (mask proposals) на изображении.

* Основан на **суперпикселях** (agglomerated pixel clusters), чтобы снизить вычислительную сложность.
* Использует **Graph Cut** для разделения изображения на фон и объект.
* Генерирует **Grid и Subframe Seeds**, чтобы создавать множество вариантов масок.
* Для оценки масок используется **энергия**, отражающая качество сегментации.

---

## Теоретические основы

### 1. Суперпиксели

**Суперпиксель** — это объединение смежных пикселей с похожими характеристиками (цвет, текстура).

* **Цель:** уменьшить количество узлов в графе и сгладить шум.
* В проекте поддерживаются два метода:

  * **SLIC (Simple Linear Iterative Clustering)** — кластеризация пикселей по пространству + цвету.
  * **Felzenszwalb** — графовая сегментация, ориентированная на локальные различия в регионе.

---

### 2. Graph Cut

**Graph Cut** — алгоритм, который минимизирует энергию сегментации:

[
E(L) = \sum_i U_i(L_i) + \sum_{i,j} V_{i,j}(L_i,L_j)
]

где:

* (U_i) — **унарный терм** (data cost), отражает вероятность принадлежности суперпикселя к объекту или фону.
* (V_{i,j}) — **парный терм** (smoothness), штраф за разрыв между соседними суперпикселями.
* (L_i \in {0,1}) — метка суперпикселя (0 — фон, 1 — объект).

**Цель Graph Cut:** найти разметку (L), которая минимизирует (E(L)).

---

### 3. Унарные термы (Unary terms)

* Если используется цветовая информация (`use_color_unary=True`):

[
U_i = \exp\Big(- \frac{\chi^2(H_i,H_{seed})^2}{2 \sigma^2} \Big)
]

* (\chi^2) — χ² расстояние между гистограммами цветов суперпикселя и сидового суперпикселя.
* Если `use_color_unary=False` — все суперпиксели имеют одинаковую вероятность (0.5).

---

### 4. Парные термы (Pairwise / Smoothness)

[
V_{i,j} = \exp\Big(-\frac{|mean_color_i - mean_color_j|^2}{2 \sigma^2}\Big)
]

* Вес ребра между соседними суперпикселями зависит от **различия цветов** (`mean_color` в Lab).
* Чем меньше различие, тем сильнее ребро → меньше вероятность разрыва объекта.

---

### 5. Сиды (Seeds)

**Seeds** — суперпиксели, которые задают исходные точки для объектов/фона.

1. **Grid Seeds** — регулярная сетка по всему изображению.
2. **Subframe Seeds** — центры подфреймов (subframes).

   * Внутри subframe сид считается объектом.
   * Пиксели за пределами subframe считаются фоном (boundary seeds).

Сиды нужны, чтобы получить разнообразные маски.

---

### 6. Энергия маски

[
E = \frac{\text{boundary edges}}{\text{boundary edges + internal edges}}
]

* **boundary edges** — ребра между объектом и фоном.
* **internal edges** — ребра внутри объекта.
* Чем ниже энергия, тем более “связная” и качественная маска.

## src/cpmc_superpixels.py

Функции работы с суперпикселями:

1. **compute_superpixels(img, scale=100, sigma=0.5, min_size=50)**

   * Генерация суперпикселей методом Felzenszwalb.
   * Параметры:

     * `scale` — чувствительность к различию внутри региона.
     * `sigma` — сглаживание изображения перед сегментацией.
     * `min_size` — минимальный размер сегмента.
   * Возвращает: `segments` — массив меток суперпикселей.

2. **superpixel_stats(img, segments)**

   * Вычисляет средний цвет суперпикселя в Lab.
   * Используется для вычисления веса ребер (smoothness).

3. **superpixel_histograms(img, segments, bins=16)**

   * Строит гистограммы цвета каждого суперпикселя (L, a, b).
   * Используется для χ² расстояния при унарном терме.

4. **chi2_distance(h1, h2)**

   * Вычисляет χ² расстояние между двумя гистограммами:

[
\chi^2(H_1,H_2) = \frac{1}{2} \sum_i \frac{(H_1(i)-H_2(i))^2}{H_1(i)+H_2(i)+\epsilon}
]

5. **superpixel_adjacency(segments)**

   * Возвращает словарь `{i: set(соседей)}` для каждого суперпикселя.

6. **grid_seeds(segments, step=50)**

   * Создает сиды по сетке.

7. **subframe_seeds(segments, subframe_ratio=0.4)**

   * Создает сиды по подфреймам.
   * Возвращает `(seed_label, boundary_seeds)` — объект и фоновый контур.

## src/cpmc_graphcut.py

**build_graph_and_cut(...)**

1. Инициализация графа с узлами = суперпикселям.
2. Добавление **парных ребер** с весами `V_{i,j}` по цвету.
3. Вычисление **унарных термов** `U_i` по цвету или равномерно.
4. Учёт **фона** через boundary seeds.
5. Принудительное назначение seed суперпикселя на объект.
6. Решение задачи максимального потока (`maxflow`).
7. Преобразование результатов в бинарную маску.
8. Фильтрация:

   * Инверсия при пустой маске.
   * Связные компоненты → оставляем самый крупный объект.

---

## src/cpmc_proposals.py

**generate_proposals(...)**

Основной конвейер генерации предложений:

1. Генерация суперпикселей (`compute_superpixels`).
2. Вычисление:

   * `mean_color` (`superpixel_stats`)
   * `histograms` (`superpixel_histograms`)
   * `adjacency` (`superpixel_adjacency`)
3. Генерация сидов (`grid_seeds`, `subframe_seeds`).
4. Формирование всех комбинаций параметров для Graph Cut:

   * λ (lam_values)
   * цветовой унарный терм (`use_color=True/False`)
   * subframe boundary seeds
5. Параллельное выполнение Graph Cut (`multiprocessing.Pool`).
6. Фильтрация масок:

   * Пустые
   * Дубликаты (через IoU)
   * По размеру (min_size/max_size)
7. Вычисление **энергии масок** (`calculate_energy`).
8. Сортировка по энергии → выбор `top_k` масок.
9. Сохранение масок, кропов и CSV файла.

---

## Вспомогательные функции

* **mask_bbox(mask)** — bounding box маски.
* **score_mask(mask)** — отношение площади маски к площади изображения.
* **iou(a,b)** — пересечение по объединению двух масок.
* **dedup(masks, thr=0.9)** — удаление дубликатов по IoU.
* **calculate_energy(mask, segments, mean_color, adjacency)** — энергия маски.

## Пример использования

```python
import cv2
from src.cpmc_proposals import generate_proposals

img = cv2.imread("images/cat.jpg")
out_dir = "output/"

proposals = generate_proposals(
    img,
    "cat.jpg",
    out_dir,
    n_segments=800,
    compactness=7,
    lam_values=[0.05,0.1,0.2,0.5,1,2,5,10],
    top_k=200,
    use_subframes=True,
    workers=4
)
```

* Результат: список объектов `Proposal(mask, bbox, score, area, energy)`.
* Файлы на выходе:

  * Маски объектов (`_mask_XXX.png`)
  * Кропы объектов (`_crop_XXX.jpg`)
  * CSV файл с информацией о каждой маске.

## Параметры настройки

| Параметр      | Описание                                    |
| ------------- | ------------------------------------------- |
| n_segments    | Количество суперпикселей                    |
| compactness   | Регулярность суперпикселей (SLIC)           |
| scale         | Чувствительность сегментации (Felzenszwalb) |
| sigma         | Сглаживание перед сегментацией              |
| lam_values    | λ для унарного терма (баланс фон/объект)    |
| top_k         | Количество финальных масок                  |
| grid_step     | Шаг для Grid seeds                          |
| use_subframes | Использовать subframe seeds                 |
| workers       | Количество потоков для multiprocessing      |
